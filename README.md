Welcome to my repository for the **[IBM AI Engineering Professional Certificate](https://www.coursera.org/professional-certificates/ai-engineer)** on Coursera! 

This repository documents my journey through the certificate program. Notably, I am taking an active approach to this learning experience: rather than just following along, I am **rewriting and modernizing the legacy lab code** provided in the course to adhere to current industry best practices (utilizing modern `scikit-learn`, `pandas`, `PyTorch`, `TensorFlow`, and clean Python syntax). 

Additionally, this repository contains clean, structured Markdown notes summarizing the core concepts from the transcripts and lectures.
