Lecture Video 1: Regression Tree.

Summary: 
This lecture explains the concept and construction of regression trees, a type of decision tree used for predicting continuous values.

Definition and Differences from Classification Trees

Regression trees predict continuous target variables, unlike classification trees which predict categorical classes.
The prediction at leaf nodes in regression trees is the average of target values, whereas classification trees use majority class voting.
Creation and Splitting Criteria

Regression trees are built by recursively splitting the dataset to minimize variance within nodes.
Splits are evaluated using mean squared error (MSE), aiming to reduce the weighted average MSE of resulting subsets.
Handling Features and Thresholds

For continuous features, candidate split thresholds are chosen as midpoints between sorted unique values.
For binary or multi-class features, splits are made by separating classes or using strategies like one-versus-one to find the best binary split minimizing MSE.
Prediction and Optimization

Predictions at nodes are typically the mean of target values, but median can be used for skewed data.
The training process selects features and thresholds that minimize prediction variance, improving regression accuracy.

# 🌳 Regression Trees — Explained from Scratch

A **Regression Tree** is a type of **Decision Tree** used when we want to predict a **continuous numerical value**.

For example:

* Predict a person's **salary** → `85,000`
* Predict tomorrow's **temperature** → `32.5°C`
* Predict house **price** → `$250,000`
* Predict company's **revenue** → `$1.2M`

The main idea is:

> **Keep splitting the data into smaller groups so that the target values inside each group become as similar as possible.**

---

## 1. Regression Tree vs Classification Tree

This is the most important distinction.

|                 | Classification Tree | Regression Tree |
| --------------- | ------------------- | --------------- |
| Target          | Categorical         | Continuous      |
| Prediction      | Class               | Number          |
| Example         | Spam / Not Spam     | House Price     |
| Leaf prediction | Majority class      | Average target  |
| Split criterion | Gini / Entropy      | MSE / Variance  |

### Classification example

Suppose a leaf contains:

```text
Spam
Spam
Not Spam
Spam
```

The tree predicts:

```text
Spam
```

because **Spam is the majority class**.

### Regression example

Suppose a leaf contains house prices:

```text
200,000
210,000
220,000
```

The tree predicts:

[
\hat y = \frac{200000+210000+220000}{3}
]

[
\hat y = 210000
]

So:

> **Classification → majority vote**
> **Regression → average value**

# 2. What Does a Regression Tree Look Like?

Imagine we're predicting **house prices** based on house size.

```text
                 Size < 1500?
                  /        \
                Yes         No
                /            \
          Size < 1000?     Price = 300k
           /      \
         Yes      No
         /         \
     Price=150k   Price=220k
```

Suppose a new house has:

```text
Size = 1200 sq ft
```

The tree asks:

```text
1200 < 1500?
```

Yes.

Then:

```text
1200 < 1000?
```

No.

Therefore:

```text
Prediction = 220k
```

Notice something important:

The tree isn't necessarily predicting a value that existed in the training dataset. It predicts the **average target value of the training samples that reached that leaf**.

# 3. How Does the Tree Decide Where to Split?

This is the heart of regression trees.

Suppose we have:

| Size | Price |
| ---: | ----: |
|  800 |   150 |
|  900 |   160 |
| 1200 |   200 |
| 1500 |   250 |
| 1800 |   300 |
| 2000 |   320 |

The tree could try:

```text
Size < 1000
Size < 1350
Size < 1650
Size < 1900
...
```

For every possible split, it asks:

> **"After splitting the data, how similar are the target values inside each group?"**

We want the groups to have **low variance**.

---

# 4. MSE — The Main Criterion

Regression trees commonly use **Mean Squared Error (MSE)** to measure how good a split is.

The formula is:

[
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y)^2
]

Where:

* (y_i) = actual value
* (\hat y) = predicted value
* (n) = number of observations

For a regression tree node:

[
\hat y = \text{mean of target values in the node}
]

---

## 5. Simple MSE Example

Suppose one node contains:

```text
10
12
14
```

The prediction is the mean:

[
\hat y = \frac{10+12+14}{3}=12
]

Now calculate errors:

```text
10 → 10 - 12 = -2
12 → 12 - 12 = 0
14 → 14 - 12 = 2
```

Square them:

```text
4
0
4
```

Therefore:

[
MSE = \frac{4+0+4}{3}
]

[
MSE = 2.67
]

So this node has an MSE of approximately:

```text
2.67
```

---

# 6. Why Does MSE Work?

Think about these two groups.

### Group A

```text
10
11
10
12
11
```

The values are very close.

### Group B

```text
2
50
90
15
70
```

The values are spread out.

Group A has **low variance**.

Group B has **high variance**.

A good regression tree wants:

> **Low variance inside each leaf.**

That's why we minimize MSE.

# 7. Weighted MSE of a Split

Suppose we split our data into two nodes:

```text
             Root
            /    \
         Left    Right
```

The left node has:

```text
n_left = 4
MSE_left = 10
```

The right node has:

```text
n_right = 6
MSE_right = 20
```

Total observations:

[
n = 4+6=10
]

The weighted MSE is:

[
MSE_{split}
===========

\frac{
n_{left}MSE_{left}
+
n_{right}MSE_{right}
}{
n_{left}+n_{right}
}
]

Therefore:

[
MSE_{split}
===========

\frac{4(10)+6(20)}{10}
]

[
=\frac{40+120}{10}
]

[
=16
]

So this particular split has:

```text
Weighted MSE = 16
```

The tree will compare this against other possible splits.

# 8. How the Tree Chooses the Best Split

Suppose we have three candidate splits:

| Split       | Weighted MSE |
| ----------- | -----------: |
| Size < 1000 |         25.4 |
| Size < 1400 |     **12.8** |
| Size < 1700 |         19.2 |

The tree chooses:

```text
Size < 1400
```

because:

[
12.8 < 19.2 < 25.4
]

Therefore:

> **The best split is the one with the lowest weighted MSE.**

# 9. How Are Thresholds Chosen?

For a continuous feature, the lecture describes an **exhaustive search** approach.

Suppose our feature values are:

```text
10
20
30
40
50
```

First, sort them:

```text
10 < 20 < 30 < 40 < 50
```

Then calculate the midpoint between consecutive values.

### Between 10 and 20

[
\frac{10+20}{2}=15
]

### Between 20 and 30

[
\frac{20+30}{2}=25
]

### Between 30 and 40

[
\frac{30+40}{2}=35
]

### Between 40 and 50

[
\frac{40+50}{2}=45
]

Candidate thresholds become:

```text
15
25
35
45
```

The tree tests each one and chooses the threshold producing the **lowest weighted MSE**.

---

# 10. Why Use Midpoints?

Consider:

```text
10   20   30   40
```

A threshold of `20` and a threshold of `25` might produce the same partition:

```text
Left: 10, 20
Right: 30, 40
```

Using the midpoint:

```text
25
```

gives us a clean threshold between the two neighboring values.

So the general rule is:

[
\alpha_i = \frac{x_i+x_{i+1}}{2}
]

where (x_i) and (x_{i+1}) are consecutive unique sorted feature values.

---

# 11. What About Duplicate Values?

Suppose we have:

```text
10
20
20
20
30
40
```

We don't need to consider thresholds between:

```text
20 and 20
```

because there's no meaningful separation there.

So we first consider unique values:

```text
10
20
30
40
```

Then candidate thresholds:

```text
15
25
35
```

# 13. Mean vs Median

Normally, regression trees use the **mean** at a leaf.

For example:

```text
10
12
14
```

Prediction:

[
\frac{10+12+14}{3}=12
]

But what happens if we have an outlier?

```text
10
12
14
100
```

Mean:

[
\frac{10+12+14+100}{4}=34
]

That's heavily influenced by `100`.

The **median** would be:

```text
13
```

So for highly skewed data, the median can sometimes provide a more robust prediction.

The important point from the lecture is:

> **Mean is the typical prediction used by regression trees, while other statistics such as the median can be used depending on the problem.**

# 14. The Complete Training Process

Let's put everything together.

Suppose we're predicting:

```text
House Price
```

using:

```text
House Size
Bedrooms
Age
```

The regression tree does roughly this:

### Step 1 — Start with all training data

```text
All houses
```

### Step 2 — Look at possible features

```text
House Size
Bedrooms
Age
```

### Step 3 — Generate possible splits

For example:

```text
Size < 1000
Size < 1500
Size < 2000

Age < 5
Age < 10
Age < 20

Bedrooms < 3
Bedrooms < 4
```

### Step 4 — Calculate MSE

For every possible split:

```text
Calculate left-node MSE
Calculate right-node MSE
Calculate weighted MSE
```

### Step 5 — Choose the best split

Pick:

```text
Lowest weighted MSE
```

### Step 6 — Repeat recursively

Each resulting node can be split again.

```text
                 Size < 1500?
                /            \
              Yes             No
             /                 \
       Age < 10?             Size < 2200?
       /      \               /       \
      ...     ...            ...      ...
```

### Step 7 — Stop splitting

Eventually the tree reaches stopping conditions such as:

* Maximum tree depth
* Minimum number of samples required to split
* Minimum number of samples in a leaf
* No useful improvement from another split

Then we have our final regression tree.

# 17. Important Correction in the Lecture

The transcript says:

> "Regression trees are created by recursively splitting the dataset into subsets to maximize information gained from data splitting."

This wording is primarily associated with **classification trees**.

For regression trees, the more precise way to think about it is:

> **Recursively choose the feature and threshold that minimize the weighted prediction error, commonly measured using MSE.**

So don't get confused between:

```text
Classification
→ Entropy / Information Gain / Gini
```

and

```text
Regression
→ MSE / Variance reduction
```
